The campaign's action button: uppercase Hanken Grotesk Bold on a two-corner chamfer, lime for primary intent.

```jsx
<Button variant="primary" size="lg" icon="seta">Ver ofertas</Button>
<Button variant="outline">Falar com consultor</Button>
<Button variant="onDark" as="a" href="#">Baixar catálogo</Button>
```

- `primary` lime / `secondary` terra / `outline` / `ghost` / `onDark` (for terra backgrounds).
- Chamfer scales with size; press state nudges down 1px, never scales.
