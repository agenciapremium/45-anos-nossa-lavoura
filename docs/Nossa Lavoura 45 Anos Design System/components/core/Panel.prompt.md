The brand's container: a softly rounded surface. Use it for every block-level surface.

```jsx
<Panel tone="terra" radius="var(--radius-surface)">…</Panel>
<Panel tone="card" bordered>…</Panel>
```

Radius steps: `--radius-control` 12 (controls) · `--radius-card` 20 (cards/panels) · `--radius-surface` 32 (dialogs, hero blocks). The octagon is never a container shape — it only appears as a background element (see `Octagon`).
