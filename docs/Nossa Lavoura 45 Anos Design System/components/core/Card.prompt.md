Product or content card: rounded surface, optional cover image, eyebrow + title + copy, optional pictogram.

```jsx
<Card eyebrow="Nutrição" title="Linha Cria" description="Proteinado para bezerros na seca." icon="boi" onClick={go} />
```

Hover lifts 3px only when `onClick` is set. Use `tone="terra"` for a highlight card in a light grid.
